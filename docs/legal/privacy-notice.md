# ร่าง — ประกาศความเป็นส่วนตัว (Privacy Notice) ระบบชำระเงินโรงอาหาร

> **ร่างเพื่อให้ทนายความตรวจก่อนใช้จริง** ข้อความใน [ ] ต้องแก้ให้ตรงกับแต่ละโรงงาน
> โครงสร้างตาม พ.ร.บ.คุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 (PDPA): บริษัทนายจ้างเป็น **ผู้ควบคุมข้อมูล**
> บริษัท โกอะลอง จำกัด เป็น **ผู้ประมวลผลข้อมูล** ตามสัญญาประมวลผลข้อมูล (DPA) ที่ต้องลงนามแยก

---

**[ชื่อบริษัทนายจ้าง]** ("บริษัท") ให้บริการระบบชำระเงินในโรงอาหารแก่พนักงาน โดยใช้ระบบของบริษัท โกอะลอง จำกัด ("ผู้ให้บริการระบบ") ประกาศนี้อธิบายว่าบริษัทเก็บ ใช้ และเปิดเผยข้อมูลส่วนบุคคลของท่านอย่างไร

## 1. ข้อมูลที่เก็บ

| ข้อมูล | แหล่งที่มา |
|---|---|
| ชื่อ-นามสกุล รหัสพนักงาน แผนก | ฝ่ายบุคคล |
| หมายเลขโทรศัพท์มือถือ (ถ้ามี) | ฝ่ายบุคคล / ท่าน |
| รหัส PIN (เก็บแบบเข้ารหัสทางเดียว ไม่มีผู้ใดอ่านได้) | ท่าน |
| รหัสผู้ใช้ LINE (เมื่อท่านเลือกเชื่อมบัญชี LINE) | LINE |
| รายการใช้จ่าย: ร้าน จำนวนเงิน วันเวลา ช่องทาง | ระบบ |
| ข้อมูลอุปกรณ์และการเข้าใช้งาน: รหัสอุปกรณ์ หมายเลข IP เวลาเข้าระบบ | ระบบ |

บริษัทไม่เก็บรูปถ่าย ข้อมูลชีวภาพ หรือเลขบัตรประชาชนในระบบนี้ การปลดล็อกด้วย Face ID หรือลายนิ้วมือทำบนเครื่องของท่านเท่านั้น

## 2. วัตถุประสงค์และฐานทางกฎหมาย

| วัตถุประสงค์ | ฐานทางกฎหมาย |
|---|---|
| ให้ท่านชำระค่าอาหารและใช้สวัสดิการค่าอาหาร | ปฏิบัติตามสัญญาจ้าง / สวัสดิการ |
| หักค่าอาหารส่วนที่เกินสวัสดิการจากเงินเดือน ตามที่ท่านยินยอมไว้ | ความยินยอมเป็นหนังสือตาม พ.ร.บ.คุ้มครองแรงงาน + สัญญา |
| ชำระเงินให้ร้านค้าในโรงอาหาร | ประโยชน์โดยชอบด้วยกฎหมาย |
| ป้องกันการทุจริตและรักษาความปลอดภัยของบัญชี | ประโยชน์โดยชอบด้วยกฎหมาย |
| จัดทำบัญชีและเอกสารตามกฎหมาย | หน้าที่ตามกฎหมาย |

## 3. ผู้ที่ได้รับข้อมูล

- ฝ่ายบุคคลและฝ่ายบัญชีของบริษัท เท่าที่จำเป็นต่อหน้าที่
- ร้านค้าในโรงอาหาร: เห็นเฉพาะชื่อของท่านและยอดที่ท่านชำระให้ร้านนั้น
- บริษัท โกอะลอง จำกัด ในฐานะผู้ประมวลผลข้อมูล และผู้ให้บริการส่ง SMS [ชื่อผู้ให้บริการ SMS] เพื่อส่งรหัส OTP
- หน่วยงานรัฐเมื่อมีกฎหมายกำหนด

ข้อมูลจัดเก็บบนเซิร์ฟเวอร์ใน [ประเทศไทย / ระบุที่ตั้ง]

## 4. ระยะเวลาเก็บ

- ข้อมูลบัญชีผู้ใช้: ตลอดระยะเวลาจ้างงาน และลบหรือทำให้ไม่สามารถระบุตัวตนได้ภายใน [90] วันหลังสิ้นสุดการจ้างและชำระยอดคงค้างครบ
- รายการใช้จ่าย: [5] ปี ตามระยะเวลาเก็บเอกสารบัญชี
- บันทึกการเข้าใช้งาน: [1] ปี

## 5. สิทธิของท่าน

ท่านมีสิทธิขอเข้าถึง ขอรับสำเนา ขอแก้ไข ขอลบ ขอระงับ คัดค้าน และขอโอนย้ายข้อมูล และถอนความยินยอมได้ (การถอนความยินยอมหักเงินเดือนจะมีผลกับรอบถัดไป และท่านจะใช้ได้เฉพาะยอดสวัสดิการ) รวมถึงร้องเรียนต่อสำนักงานคณะกรรมการคุ้มครองข้อมูลส่วนบุคคล
